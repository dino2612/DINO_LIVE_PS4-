# DINO LIVE PS4

## Sobre o projeto

Aplicativo homebrew para PS4 com interface preta e roxa neon.

## Versão 0.1

- Tela inicial
- Painel do YouTube
- Configurações de áudio
- Teste de captura permitida
- Indicadores de status

## Identidade visual

- Preto como cor principal
- Roxo neon nos detalhes
- Interface moderna
- Navegação simples

## Desenvolvimento

Primeiro objetivo: criar uma versão inicial que abra no PS4.

A transmissão será implementada posteriormente, respeitando as limitações de captura e as APIs autorizadas.
