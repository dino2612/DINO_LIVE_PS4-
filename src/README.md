# Código-fonte DINO LIVE PS4

## Organização

- main.c: entrada principal do aplicativo
- interface/: menus e telas
- youtube/: integração autorizada com YouTube
- audio/: gerenciamento de áudio
- capture/: testes de captura permitida
- status/: indicadores do sistema

## Plataforma

- PlayStation 4
- OpenOrbis PS4 Toolchain
- Linguagem C/C++

## Objetivo inicial

Preparar uma versão de teste que possa ser
compilada e executada no PS4.

A transmissão será desenvolvida em etapas
posteriores.
